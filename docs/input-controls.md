# 输入控制

这些能力属于酷米前端，适用于支持的输入方案，不依赖万象。

## 应用默认模式

设置 → 应用可配置默认中文或英文。开启“进入时重置”后，每次进入文本框恢复该应用默认模式；关闭时沿用已有中英文状态记忆策略。菜单栏“当前应用临时模式”可临时指定中文、英文或恢复应用设置，临时覆盖在输入法进程重启后失效。

## 候选词管理

右键候选可设置本页优先、降低优先级或隐藏，并撤销上次调整。规则按输入方案、完整编码和词语保存；仅重新排列或过滤当前页，不修改 Rime 词库、学习频率或跨页排序。

目前仅适用于普通小写字母编码、标准数字选词的候选列表。特殊前缀、计算器等输入及自定义选词键保留方案行为。全部隐藏时可继续翻页，或到设置 → 候选词管理恢复规则。该页支持搜索、恢复默认和单步撤销。

规则保存在用户目录的 `kume/candidate-preferences.json`，无需重新部署。

## 快捷键冲突提示

设置 → 快捷键显示酷米固定快捷键、方案切换键与首选方案按键绑定之间的重复键位。不同触发条件可能允许共用按键，因此提示是潜在冲突；不检测系统和其他应用的快捷键。

## 设置搜索

设置窗口顶部支持搜索标题、说明、配置键和常见别名，例如“字号”“英文”“翻页”。结果可直接修改，也提供应用、候选词管理、快捷键冲突的入口。
